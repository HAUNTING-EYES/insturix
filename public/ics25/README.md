# ICS25 public assets

Place esports imagery here to be used by GameOn frames and other sections.

- Primary background: `gameon-frames.jpg` (recommended 2400×1350 or larger, 16:9)
- Format: Prefer JPG with reasonable compression; PNG if transparency required.
- Licensing: Ensure you own rights or have permission.

If `gameon-frames.jpg` is missing, the UI gracefully falls back to gradients without breaking layout.
