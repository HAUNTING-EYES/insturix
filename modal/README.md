# Editron Modal Workers

This folder holds Modal-hosted helpers used by Editron. The chapter-concat worker is the live ops item from the 2026-06-27 handoff: code is built, but the service must be deployed and wired before renders over the chapter threshold can return one stitched MP4.

## Chapter Concat

Worker: `modal/concat_chapters.py`

Purpose:

- Accept ordered chapter MP4 URLs from the Next worker.
- Validate bearer auth, job id, and storage hosts.
- Download chapters into Modal disk.
- Run ffmpeg concat with stream copy.
- Upload `editron-concat/<jobId>.mp4` back to the same S3 bucket.
- Return `{ ok, url, sizeBytes, chapters }`.

### Required Secrets

Create one Modal secret named `editron-chapter-concat`:

```powershell
python -m modal secret create editron-chapter-concat `
  EDITRON_CHAPTER_CONCAT_TOKEN=<shared-long-random-token> `
  AWS_ACCESS_KEY_ID=<remotion-output-bucket-key> `
  AWS_SECRET_ACCESS_KEY=<remotion-output-bucket-secret>
```

The token must match `EDITRON_CHAPTER_CONCAT_TOKEN` on the Next/Vercel side.

### Deploy

```powershell
python -m modal deploy modal/concat_chapters.py
```

Record the deployed endpoint URL, usually shaped like:

```text
https://<workspace>--editron-chapter-concat-concat.modal.run
```

Set these on Vercel preview and production, and in `.env.local` for local smoke tests:

```text
EDITRON_CHAPTER_CONCAT_ENDPOINT=<modal-endpoint-url>
EDITRON_CHAPTER_CONCAT_TOKEN=<same-shared-token>
```

`QSTASH_TOKEN` must also be present so `chapter-renderer.ts` can enqueue the async worker.

### Smoke Test

Use two short chapter MP4 URLs from the same allowed storage/CDN family. The URLs should be generated by the renderer, not arbitrary internet media.

```powershell
$headers = @{
  "Authorization" = "Bearer $env:EDITRON_CHAPTER_CONCAT_TOKEN"
  "Content-Type" = "application/json"
}

$body = @{
  jobId = "smoke_concat_$(Get-Date -Format yyyyMMddHHmmss)"
  chapters = @(
    "<chapter-0-url>",
    "<chapter-1-url>"
  )
} | ConvertTo-Json

Invoke-RestMethod `
  -Method Post `
  -Uri $env:EDITRON_CHAPTER_CONCAT_ENDPOINT `
  -Headers $headers `
  -Body $body
```

Acceptance:

- Response has `ok: true`.
- Returned `url` points to `editron-concat/<jobId>.mp4`.
- The MP4 opens and duration is roughly the sum of the input chapters.
- No visible or audible gap exists at the chapter seam.
