# Dashboard Redesign Decisions — 2026-05-14

## Musitron
- **Generation screen**: Recording Studio (musitron-1) — mixing console metaphor for creating music
- **Collections screen**: Jukebox (musitron-2) — browse previous generations in playable format
- **REJECTED**: Frequency (3), Setlist (4)

## Org
- **Main view**: Constellation (org-2) — members as stars with connections
- **Stats detail**: Merge Crew Manifest (org-3) detailed stats into Constellation's visual style
- **Brand Vault**: Repurpose War Room (org-1) concept as a brand vault — users see how brand assets are connected, can add nodes (knowledge graph visualization for brand)
- **REJECTED**: War Room (1) for org, Roundtable (4)
- **Note**: Brand Vault is a NEW feature concept, not just a redesign

## Credits
- **Main view**: Receipt Tape (credits-4) — thermal receipt metaphor
- **Secondary**: Vault (credits-2) liked but Receipt Tape chosen as primary
- **REJECTED**: Fuel Gauge (1), Energy Grid (3)
- **Next**: Restyle receipt in Insturix dark color scheme (currently off-white paper), add alive/moving animated elements

## User's Design Taste (confirmed across sessions)
- Dark luxury (#0B0B0A, #D4A652 gold)
- Animations that feel alive (pulse, glow, draw-on-load, traveling energy)
- Every element has meaning — no decoration without function
- Platform/brand colors for visual richness
- Breathing room — decluttered, not crammed
- Interactive connections between elements
- Narrative/metaphorical labels that give personality
- JetBrains Mono for data, Plus Jakarta Sans for body
