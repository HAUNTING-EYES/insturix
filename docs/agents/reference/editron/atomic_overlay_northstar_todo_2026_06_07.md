# Atomic Overlay Northstar TODO - 2026-06-07

## Current Northstar

The editing system should move from `label -> preset` toward:

`atoms + relations + rhythm + screen context + brand taste + learned references -> form`

Labels can remain as compatibility output, but they should not be the source of truth. Weird or unknown content should preserve its atoms/evidence first and render conservatively until calibration learns a better form.

## Done Recently

- MG content gets an atomic structural signature before legacy kind projection.
- Non-MG overlays now stamp atomic receipts/forms for timing, placement, motion, style, content, constraints, and collisions.
- Text/caption overlays now expose atomic glyphs, hierarchy, emphasis, line breaks, casing, font/color roles, highlight, motion, and row composition.
- Caption/text renderers consume atomic `fontPlan` and `colorPlan`.
- Zoom and transition forms are signal-shaped and still project compatibility types for legacy rendering.
- V-JEPA primitives are wired as metadata inputs: subject bbox, text boxes/coverage, negative space, motion vector, object/face counts.
- A deterministic atomic aesthetic gate exists for placement, text, motion, rhythm, and variety.

## Next TODO

- Feed aesthetic failures back into resolver weights/curves instead of only reporting them.

- Continue removing preset-like resolution from MG, zoom, transition, caption, text, SFX, and other overlay families.

## Calibration Principle

Calibration should not teach the system to chase a single creator. Use a wide creator/reference set by format and style, then tune signal weights/curves toward robust patterns:

- hooks and claims
- talking-head education
- luxury/product
- vlog/creator energy
- documentary/narrative
- screen-record/tutorial
- podcast/interview
- music/beat-driven edits

The reference target is not "copy Iman." The target is: layered timing, readable hierarchy, tasteful restraint, and form choices that feel intentional for the moment.
