## Key Principles

1. **Murch's Rule of Six:** Emotion (51%) > Story (23%) > Rhythm (10%) > Eye-trace (7%) > 2D Plane (5%) > 3D Continuity (4%)
2. **Decisive Moment:** Every scene has ONE peak — all decisions serve it
3. **Invisible Edit:** Best editing is invisible. Max 2-3 "loud" decisions per 30s
4. **Contrast Creates Impact:** Fast only feels fast after slow. Track previousDecisionIntensity
5. **Hard Override Rules (Weight 10):** These can NEVER be violated regardless of other rules
